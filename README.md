# Задание: Figures (Геометрические фигуры)

Основано на учебном проекте [ipetrushin/Figures](https://github.com/ipetrushin/Figures).

## Реализованная функциональность

1. **Интерфейс `Transforming`**:
   - `resize(zoom: Int)` — масштабирование размеров фигуры без смещения её позиции с сохранением пропорций.
   - `rotate(direction: RotateDirection, centerX: Int, centerY: Int)` — поворот фигуры вокруг произвольной точки `(centerX, centerY)` на 90 градусов (по часовой или против часовой стрелки).
2. **Наследование от `Figure`**:
   - `Rect`, `Square`, `Circle` наследуются от `Figure(0)` и реализуют метод вычисления площади `area(): Float`.
3. **Интерфейс `Movable`**:
   - `move(dx: Int, dy: Int)` — смещение позиции фигуры на вектор `(dx, dy)`.
4. **Классы фигур**:
   - `Rect(var x: Int, var y: Int, var width: Int, var height: Int)`
   - `Square(var x: Int = 0, var y: Int = 0, var side: Int = 1)`
   - `Circle(var x: Int = 0, var y: Int = 0, var radius: Int = 1)`

## Математическая модель поворота на 90°

Для любой точки $(p_x, p_y)$ относительно центра поворота $(c_x, c_y)$ ($\Delta x = p_x - c_x$, $\Delta y = p_y - c_y$):

- **По часовой стрелке (`RotateDirection.Clockwise`):**
  $$p_x' = c_x + \Delta y = c_x + (p_y - c_y)$$
  $$p_y' = c_y - \Delta x = c_y - (p_x - c_x)$$

- **Против часовой стрелки (`RotateDirection.CounterClockwise`):**
  $$p_x' = c_x - \Delta y = c_x - (p_y - c_y)$$
  $$p_y' = c_y + \Delta x = c_y + (p_x - c_x)$$

### Соответствие схеме с занятия (GeoGebra)

![Схема поворота в GeoGebra](./Figures/assets/geogebra_rotation.png)

1. **Исходный прямоугольник:**
   - $A_1(2,2)$, $B_1(6,2)$, $C_1(6,4)$, $D_1(2,4)$
   - $x = 2$, $y = 2$, $width = 4$, $height = 2$, центр = $(4, 3)$.
2. **Центр поворота:** $(3, -3)$.
3. **После поворота Clockwise:**
   - Вершины: $B(8,-2), C(8,-6), D(10,-6), E(10,-2)$
   - $x = 8$, $y = -6$, $width = 2$, $height = 4$, центр = $(9, -4)$.
4. **После поворота CounterClockwise:**
   - Вершины: $F(-4,0), G(-4,-4), H(-2,-4), I(-2,0)$
   - $x = -4$, $y = -4$, $width = 2$, $height = 4$, центр = $(-3, -2)$.
