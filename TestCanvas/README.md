# TestCanvas

Сравнение размеров View элемента в `onLayout()` и размеров Canvas в `onDraw()`.

## Результаты
* **Единицы измерения:** физические пиксели (`px`).
* **Сравнение:** размеры View из `onLayout()` и Canvas из `onDraw()` совпадают (`1080 x 2034 px`).
